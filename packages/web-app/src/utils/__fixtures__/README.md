`anchorEquipment.json` contains hand-annotated anchor-cell excerpts and
business-rule examples for offline regression tests. They cover French and
international abbreviations, explicit inventories, linked materials,
deviations, optional points, dimensions, alternatives and unsupported systems.
Source URLs identify public Grottocenter data (CC-BY-SA-3.0); the excerpts retain
neither entire sheets nor API responses.

Vector order: bolt hangers, carabiners, expansion bolts, soft anchors, slings.
Each G/EB includes a bolt hanger, including deviations on that support.
The final category is displayed as accessory cords (cordelettes in French);
the original source notation, including mentions of slings, is preserved.
`min` and `max` validate interpreted contributions, not completeness of an
ambiguous cell. Status-only cases check that unknown or partial descriptions
remain distinguishable. These fixtures describe supported notation rather than
measured accuracy or worldwide representativeness. No network access is needed
to run the tests; full sheets and exploratory corpora are outside the repository.
