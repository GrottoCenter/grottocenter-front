The 82 anchor-cell regressions in `anchorEquipment.json` were hand annotated
during the 2026-10-10 rigging study: 40 additional source cells, 8 international
source cells, 14 business-rule examples, and 20 source cells checked after the
research prototype was frozen. Source URLs identify public Grottocenter data
(CC-BY-SA-3.0); these excerpts retain neither entire sheets nor API responses.

Vector order: bolt hangers, carabiners, expansion bolts, soft anchors, slings.
Expectations involving goujons were updated when the business rule changed
to include a bolt hanger for each G/EB, including deviations on that support.
The final category is displayed as accessory cords (cordelettes in French);
the original source notation, including mentions of slings, is preserved.
`min` and `max` validate interpreted contributions, not completeness of an
ambiguous cell. Status-only cases check that unknown or partial descriptions
remain distinguishable. No network access is needed to run these tests.

The wider study covered 290 entrances, 513 sheets and 1,578 nonempty anchor
cells in 20 countries and 7 languages, with a strong French-language majority.
The refined prototype understood all supported notation in approximately 62%
of cells, and made partial estimates in a further 26%. These are grammar
coverage figures, not measured accuracy or worldwide representativeness.
The full collection and exploratory scripts are kept outside the repository.
