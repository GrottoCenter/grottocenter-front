# Grottocenter web app

The React single-page app behind [grottocenter.org](https://grottocenter.org).
It is built with [Vite](https://vite.dev/) and lives in the `web-app` workspace
of the monorepo, so run the commands below from the repository root.

## API

Set `VITE_API_URL` in `.env.local` to choose the backend, for example
`VITE_API_URL=https://api.grottocenter.org` to use the production API. Only
`VITE_`-prefixed variables reach client code, and they are read through
`import.meta.env`.

## Search engines

Making the SPA crawlable is out of scope: it stays `noindex` and disallowed in
`robots.txt`, enforced by `src/crawlPosture.test.js`. Search visibility comes
from static pages generated by the API (GrottoCenter/grottocenter-api#1889).
See [docs/search-visibility.md](docs/search-visibility.md) for the rejected
options before adding any SEO work here.

## Available Scripts

### `yarn start`

Starts the Vite dev server with hot reload.\
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### `yarn test`

Runs the Vitest unit tests once. Use `yarn workspace @grotto-front/web-app test:watch`
for watch mode.

### `yarn build`

Builds the app for production to the `dist` folder.\
The output is minified and the filenames include content hashes.

### `yarn storybook`

Starts Storybook on [http://localhost:6007](http://localhost:6007).

### `yarn e2e:open` and `yarn e2e:run`

Open the Cypress runner, or run the end-to-end tests headless. Both need the app
running on port 3000.
